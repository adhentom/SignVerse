# Evaluation Strategy

SignVerse AI will be evaluated primarily on human comprehension and semantic preservation, not model accuracy alone.

## Planned product metrics

- Comprehension by diverse native ISL users.
- Semantic and gloss correctness.
- Correctness of facial and other non-manual markers.
- Unknown-sign and fallback rates.
- Time to first interpreted segment and sustained interpretation lag.
- Playback synchronization drift.
- Speech-to-text error by language, accent, and code-switching pattern.
- Percentage of output using validated assets.
- Correction, replay, and abandonment rates.
- Privacy incidents and unintended retention.

## Evaluation gates

Each release phase requires an agreed test corpus, reviewer protocol, acceptance thresholds, and documented limitations. Safety-sensitive or low-confidence output must have an explicit fallback behavior.
