# Third-Party Sign Research

The milestone reviewed public projects for architectural ideas only. No third-party implementation or asset was copied into SignVerse.

| Project | Relevant concept | License decision |
|---|---|---|
| DFKI MMS-Player | Timed multimodal sign representation and animation realization | GPL-3.0; concepts studied, code not imported |
| Sign-Kit | Browser avatar visualization | No clear repository license found during review; code/assets not imported |
| Audio-to-ISL-Translator | Speech/NLP/avatar pipeline separation | No clear repository license found during review; code/assets not imported |
| text_to_isl | Text preprocessing and sign sequencing | GPL-2.0; concepts studied, code not imported |
| MediaPipe-ISL-Virtual-Interpreter | MediaPipe landmark workflow | Apache-2.0 repository; no code required for this milestone |
