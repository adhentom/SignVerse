# Development Phases

## Phase 0 — Community and feasibility

Establish native ISL governance, validate target use cases, audit licenses and provenance, define gloss conventions, and approve privacy and consent requirements.

## Phase 1 — Offline text-to-ISL proof of concept

Use a constrained vocabulary, reviewed gloss output, validated sign retrieval, and a standalone player. Exit depends on human comprehension and linguistic review.

## Phase 2 — Website extension MVP

Support user-selected website text, secure sessions, the interpreter overlay, local caching, narrow permissions, and feedback capture.

## Phase 3 — YouTube captions

Add caption timing, incremental segmentation, playback buffering, synchronization, and explicitly consented speech-to-text fallback.

## Phase 4 — Google Meet pilot

Prioritize visible live captions, then assess opt-in tab audio. Add streaming recovery, context handling, participant consent, and platform-policy review.

## Phase 5 — Coverage and model improvement

Expand the governed lexicon, evaluate Indian English, Hindi, and code-switching, improve transitions and non-manual features, and introduce regional variants.

## Phase 6 — Generative virtual interpreter

Evaluate pose generation, rigging, retargeting, transition synthesis, and facial markers. Validated clip fallback remains available when generation confidence is inadequate.
